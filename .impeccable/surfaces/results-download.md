# Descargar resultados guardados

Mode: Operate

THESIS: Descargar todas las métricas seleccionadas, con criterios y procedencia visibles.
OWN-WORLD: Se conserva la interfaz nativa de Evaluación, sus paneles, controles, tipografía, colores y traducciones.
FLOW: Ejecución → modelo/fallos → preparar → ver conteo/intervalo → CSV o JSON de una única respuesta.
STATES: Sin preparar, preparando, error recuperable, cero filas y preparado. Cambiar criterios invalida cualquier resultado pendiente o listo.
MOBILE: Controles y texto envuelven a 390 px; la tabla conserva su desplazamiento horizontal existente.
SCOPE: Extensión inline dentro de Resultados, sin nueva navegación, modal o sistema visual.
